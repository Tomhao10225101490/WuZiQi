# WuZiQi - 五子棋人机对战

一个基于 React + TypeScript + Vite 的高清五子棋 Web 应用，支持玩家与 AI 对战。AI 已升级为威胁导向搜索引擎（Negamax + Alpha-Beta + 迭代加深 + 置换表 + 时间预算），在 5 秒预算内具备更强攻防能力。

## 产品目标

- 提供开箱即用的人机五子棋对战体验。
- 界面风格优雅、动画流畅、棋盘高清显示。
- 支持中等强度以上 AI 决策，而非随机落子。
- 提供完整工程化能力：Lint、单元测试、覆盖率、构建。

## 主要功能

- **19×19 路**棋盘（与标准围棋盘格线数量一致），仍按五子连珠胜负判定。
- 玩家（黑棋）vs AI（白棋）对战。
- 自动判定胜负与平局。
- 悔棋（默认撤回最近一手或一轮）。
- AI 难度（搜索深度 1~3）调节。
- 最后一步高亮标记。
- 胜负连线高亮、终局覆盖层强反馈、音效开关。

## 技术栈

- React 19
- TypeScript
- Vite 8

## 系统设计

### 目录结构

```text
src/
  ai/
    evaluate.ts        # 棋型+组合威胁评估
    minimax.ts         # Negamax + IDDFS + 时间预算
    moveOrdering.ts    # 威胁优先走法排序
    transposition.ts   # 置换表
  components/
    GomokuBoard.tsx    # Canvas 棋盘渲染与交互
    GamePanel.tsx      # 信息面板与控制项
  game/
    board.ts           # 棋盘数据与候选点生成
    rules.ts           # 胜负规则判定
    types.ts           # 类型定义
  tests/
    ai.test.ts         # AI 决策测试
    rules.test.ts      # 规则测试
    app.test.tsx       # 组件基础交互测试
  App.tsx              # 游戏流程与回合控制
  main.tsx
```

### 关键流程

1. 玩家点击棋盘落子。
2. 规则引擎校验落子、判定胜负。
3. 若未结束，轮到 AI：运行威胁排序 + 迭代加深搜索最优落点。
4. AI 落子后再次判定胜负，更新 UI 状态。

## AI 设计说明

### 1) 候选点与走法排序

- 基于邻域候选点生成，避免全盘穷举。
- 加入战术优先排序：成五点 > 堵对手成五点 > 高启发值点。
- 先做即时战术快判（直接赢棋/必须防守）再进入深搜。

### 2) 棋型评估

- 统计四方向棋型并分级赋分（活四、冲四、活三、眠三、活二等）。
- 增加组合威胁奖励（双活三、冲四活三、双冲四）。
- 评分采用更强防守权重，降低漏防概率。

### 3) 搜索框架

- Negamax + Alpha-Beta 剪枝。
- 迭代加深（IDDFS）在预算时间内逐层加深。
- 置换表缓存局面，减少重复计算。
- 轻量静态搜索（Quiescence）降低地平线效应。
- 难度映射到不同搜索深度与时间预算（最高约 5 秒）。

## UI/交互设计

- Canvas 渲染棋盘与棋子，支持高 DPI 显示。
- 棋盘木纹渐变、石子阴影与高光增强视觉质感。
- 最后落子标记强化局势感知。
- AI 思考过程显示深度/节点/耗时信息。
- 终局覆盖层 + 连线高亮 + 音效反馈，强化胜负感知。

## 质量保障

- 规则测试：覆盖横向/斜向五连核心判定。
- AI 测试：验证“有必胜点时优先取胜、对手冲四时优先防守、活三延展倾向”。
- 组件测试：基础渲染与控制项交互。

## 性能优化策略

- 候选点邻域裁剪（减少搜索分支）。
- 候选数上限控制（默认最多 16 个）。
- 通过搜索深度滑条按设备性能调节。
